# 1.0.0 — Sectioned command lists

## What changed

`Strukt\Console\Runtime\Renderer` gained a `sections()` renderer for command
lists that are grouped under optional heading labels.

```php
$renderer->sections([
    ['title' => null, 'commands' => [/* CommandDefinition ... */]],
    ['title' => 'Package Publisher', 'commands' => [/* CommandDefinition ... */]],
]);
```

Heading-less sections render their commands directly; a section with a `title`
renders the title line above its commands. The existing flat `list()` renderer
is unchanged.

## Why

The framework `Shell` needs to present commands grouped by `cfg/cmd.ini`
sections (as strukt1 did), and that grouping must stay inside the console
package that owns list formatting.

## Documentation

- None. The README's `list` examples still hold.

## Tests

- Added `tests/Unit/RendererTest.php`: alphabetical ordering of `list()`,
  heading + command rendering in `sections()`, and blank-title handling.

## Public API impact

- New public method: `Renderer::sections(array $sections): string`, accepting
  `list<array{title: string|null, commands: list<CommandDefinition>}>`.
- `Renderer::list()` remains unchanged.
